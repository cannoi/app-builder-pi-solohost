# Gitea — SoloHost overlay

- Full application source is **downloaded from GitHub** at instantiate time (`go-gitea/gitea@v1.22.3`).
- This folder only stores SoloHost install files and metadata.
- **Forbidden:** privileged containers, docker.sock mounts.
- Ports bind to `127.0.0.1` only.
