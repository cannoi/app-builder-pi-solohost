How to read this page

  • 0–3s: normal. Wait for SANDBOX READY.
  • 3–10s: container or preview may still be starting.
  • >10s still Testing…: HTML loaded, JavaScript did not run or fetch is hung.
  • Internet / DNS: ONLINE means the sandbox itself has outbound HTTPS. OFFLINE means fix the sandbox network before changing app proxy code.
  • >30s: stop waiting. Treat as sandbox/preview failure.
  • CSS pulse + this text visible = Preview can serve HTML/CSS.
  • Clock ticking = inline JS executed. Frozen clock = JS runtime dead.
