# Troubleshooting

| What you see | What it means |
| --- | --- |
| AI ● Setup needed | No provider key yet. Demo still works. |
| Gemini was unavailable | Fallback to DeepSeek if configured. |
| Release blocked | Tests failed or a secret was found. |
| Sandbox skipped | Safe mode, expected. |
| Job interrupted | Process restarted. Run the action again. |
| GitHub not configured | Local project is kept. Add a token to publish. |
